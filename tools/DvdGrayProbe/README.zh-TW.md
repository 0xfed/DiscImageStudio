# DVD 64 / E4 灰階與混合測試

[简体中文](README.md) | [繁體中文](README.zh-TW.md) | [English](README.en.md) | [日本語](README.ja.md) | [Türkçe](README.tr.md)

本工具為 **Verbatim DVD-R AZO 43533** 製作比較測試光碟：以已測試的 `A5 / 66 / B9 / 92` 為對照，比較以 `64`、`E4` 取代 `66` 後的純色、遞色混合與實際圖片效果，並獨立測試 `64` 和 `E4` 混合的效果。工具負責產生與驗證映像檔，不執行燒錄。

所有 byte 均指 **DVD 擾碼後的目標 Q 位元組**。圖集直接指定 Q；產生時使用最鄰近取樣，不進行雙線性插值或重新灰階分級。

說明、進度、專案本身的錯誤及 JSON 中的說明文字支援五種語言。命令可附加 `--language zh-CN|zh-TW|en|ja|tr|system`；預設使用 `DISC_IMAGE_STUDIO_LANGUAGE`，未設定時跟隨系統。語言選擇保留命令名稱、JSON 欄位及技術識別碼、參數、圖集與映像資料。

獨立像素佔比複核腳本 `verify_mixtures.py` 需要 Python 3 與 NumPy，可在準備檔案所在的 Windows、Linux 或 macOS 環境執行，也支援 `--language`。它僅讀取圖集，寫出測量 JSON/CSV，保留欄位、面板與列識別碼；僅翻譯說明、錯誤及測量意義。結果描述像素佔比，並非光學亮度或 ISO 編碼取樣。

```powershell
python tools/DvdGrayProbe/verify_mixtures.py --prepared "artifacts/dvd-gray-probe-64-e4" --language en
```

## 產生與驗證

需要 Windows 與 .NET 10 SDK。請自行準備 `6000 × 6000` 的四階灰階 PNG；工具固定讀取左上座標 `(2880, 1920)`、大小 `640 × 640` 的區域。該區域轉為 Gray8 後只能包含 `0 / 85 / 170 / 255`，尺寸或灰階不符時會拒絕產生。工具不縮放、不重新遞色輸入，儲存庫未附範例來源圖片。

在儲存庫根目錄執行，將 `four-level-6000.png` 換成自己的輸入路徑；`prepare` 的輸出目錄必須為空：

```powershell
dotnet run --project tools/DvdGrayProbe --configuration Release -- prepare --source "four-level-6000.png" --output-dir "artifacts/dvd-gray-probe-64-e4"

dotnet run --project tools/DvdGrayProbe --configuration Release -- generate --prepared "artifacts/dvd-gray-probe-64-e4" --output "artifacts/dvd-gray-probe-64-e4/burn.iso" --parallelism 8

dotnet run --project tools/DvdGrayProbe --configuration Release -- verify --prepared "artifacts/dvd-gray-probe-64-e4" --iso "artifacts/dvd-gray-probe-64-e4/burn.iso"
```

輸出檔案：

| 檔案 | 用途 |
|---|---|
| `burn.iso` | 實際燒錄的整片映像檔，2,297,888 個 2048-byte 磁區，共 4,706,074,624 bytes |
| `burn.iso.json` | 映像檔產生記錄與驗證資訊 |
| `probe.json` | 配置、來源圖片與參數記錄 |
| `atlas.q8` | 6000 × 6000 的直接 Q 目標圖集 |
| `code-map.png` | 以顏色區分 Q 位元組的配置導覽；顏色不代表碟面實際顏色或亮度 |
| `nominal-preview.png` | 依標稱灰階繪製的預覽；用於辨識內容，不能預測燒錄後的明暗 |

`burn.iso` 刻意不包含檔案系統，因此無法正常掛載是預期行為。燒錄時透過燒錄軟體的 **「寫入映像檔 / Write image file to disc」** 功能選取，不要將它當作一般檔案加入資料光碟。請使用 43533 光碟，並沿用上次測試的燒錄機與速度，以便比較。

**不要將兩張導覽 PNG 輸入舊版灰階圖片產生流程。** 那會重新量化，無法保留本測試光碟指定的 `64`、`E4` 及混合比例。

## 如何觀察測試光碟

從 12 點鐘方向開始，順時針共有 12 個 30° 面板，標號後半部為該面板的暗灰候選：

```text
1-66  2-64  3-E4  |  4-64  5-E4  6-66  |  7-E4  8-66  9-64  |  10-66  11-E4  12-64
```

每組三個面板使用相同輸入，調色盤分別為 `A5 / candidate / B9 / 92`。候選在不同角度重複出現並交換順序，以減少碟面位置對比較的影響。以下半徑均從光碟中心量起：

| 半徑 | 測試內容 |
|---|---|
| 24.5–25.6 mm | 內圈純色：每 15° 一個色塊，`A5、66、64、E4、B9、92` 重複四次 |
| 26.0–28.1 mm | 四階蛇形 Floyd–Steinberg 漸層；所有面板共用同一階數圖，只取代暗灰 byte |
| 28.5–30.5 mm | `64 / E4` 直接混合；每面板順時針三欄分別含 25%、50%、75% 的 `64`，其餘為 `E4` |
| 中心半徑 37.5 mm | 相同的 12.8 mm 正方形圖片裁切 |
| 45.8–47.5 mm | 候選與 `A5` 混合 |
| 47.8–49.5 mm | 候選與 `B9` 混合 |
| 49.8–51.5 mm | 候選與 `92` 混合 |
| 52.2–57.3 mm | 外圈純色，順序與內圈相同，並附 byte 標籤 |

後三條混合列的每個面板，也依順時針分為三欄：**25%、50%、75% 候選**，其餘部分使用該列指定的另一種 byte。各候選使用相同的二元 FS 遮罩。

百分比為目標像素佔比，`0 / 85 / 170 / 255` 為標稱灰階；兩者都不代表實際碟面上等距的亮度。影像格為 **20 µm**，用於測試圖片遞色後的混合尺度，並非逐個 Q 位元組交替。

輸入圖片已是四階遞色 PNG。工具擷取左上座標 `(2880, 1920)`、大小 `640 × 640` 的區域，不縮放、不再次遞色。原始實驗輸入的四階在該裁切中約佔 `24.13% / 23.90% / 22.74% / 29.24%`；換用其他輸入後，佔比會隨圖片改變，所有圖片面板只有原 `85` 階所對應的 byte 不同。

本圖集已獨立檢查 144 個混合格、4,216,432 個有效像素：排除空白後，實際佔比與目標的最大偏差為 **0.501 個百分點**；`64/E4` 直接混合列最大偏差為 **0.197 個百分點**，未混入其他 Q 位元組。完整記錄見輸出目錄的 `mixture-measurements.csv` 與 `mixture-measurements.json`。ISO 也檢查長度，並在 9 個半徑位置逐位元組核對共 2,359,296 個 payload 目標 Q；這些是數位輸出驗證，實際碟面效果仍須燒錄觀察。

## 記錄結果

先維持相同光源與正常觀看位置，比較每組三個相鄰面板；再旋轉光碟，觀察相同候選在其他位置的重複面板。最後稍微改變觀看角度，區分「正常角度穩定可見」與「僅在特定角度可見」。

重點觀察候選是否能同時與 `A5`、`B9` 區分；混合比例增加時是否呈現有序變化；圖片暗部是否恢復細節；`64 / E4` 混合是否產生比兩種純色更有用、且角度穩定的階調。對照中的 `B9` 應仍可與 `A5`、`92` 明顯區分。

可用 0 = 難以區分，1 = 特定角度可區分，2 = 正常角度穩定可區分，簡單記錄：

| 候選 | 與 A5 區分 | 與 B9 區分 | 混合三階有序、可辨 | 圖片暗部細節 | 備註 |
|---|---|---|---|---|---|
| 66 | | | | | |
| 64 | | | | | |
| E4 | | | | | |

另記 `64 / E4` 的 25%、50%、75% 三階能否彼此區分，以及是否僅在特定角度有效。是否採用第四階，應以這些實際光碟結果為準。

## 固定校準參數

本次使用已確認的 43533 校準參數：

- 起始半徑：`23.991460627731737 mm`
- 結束半徑：`57.964893657925366 mm`
- 磁區數：`2297888`
- 通道位元長度：`133.3 nm`
- 軌距多項式係數：`[-3.9256854319227684E-05, 6.964795915429256E-05, -4.670918950137523E-05]`
- 圖集：`6000 × 6000`，涵蓋 `120 × 120 mm`

這些參數用於本次光碟的空間映射；導覽圖不是實體亮度模型。
