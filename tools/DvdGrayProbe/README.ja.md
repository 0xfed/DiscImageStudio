# DVD 64 / E4 のグレースケールと混合試験

[简体中文](README.md) | [繁體中文](README.zh-TW.md) | [English](README.en.md) | [日本語](README.ja.md) | [Türkçe](README.tr.md)

このツールは **Verbatim DVD-R AZO 43533** 用の比較試験ディスクを作成します。試験済みの `A5 / 66 / B9 / 92` を対照とし、`66` を `64` または `E4` に置き換えた単色、ディザ混合、実画像の結果を比較し、`64` と `E4` の混合も別に試験します。イメージの生成と検証を行い、ディスクへの書き込みは行いません。

すべての byte 値は **DVD スクランブル後の目標 Q バイト**です。アトラスは Q を直接指定します。生成時は最近傍サンプリングで読み、双線形補間やグレー値の再量子化は行いません。

ヘルプ、進捗、プロジェクト独自のエラー、JSON 内の説明文は 5 言語に対応しています。コマンドに `--language zh-CN|zh-TW|en|ja|tr|system` を追加できます。既定では `DISC_IMAGE_STUDIO_LANGUAGE` を使用し、未設定ならシステム言語に従います。言語を選択しても、コマンド名、JSON フィールドと技術的な識別子、パラメーター、アトラスとイメージのデータは保持されます。

独立した画素占有率検証スクリプト `verify_mixtures.py` には Python 3 と NumPy が必要です。準備済みファイルがあれば Windows、Linux、macOS で実行でき、`--language` にも対応します。アトラスを読み取り、測定 JSON/CSV を出力します。フィールド、パネルと行の識別子は保持し、ヘルプ、エラー、測定の意味だけを翻訳します。結果は画素占有率を表し、光学的な明るさや ISO の符号化サンプルではありません。

```powershell
python tools/DvdGrayProbe/verify_mixtures.py --prepared "artifacts/dvd-gray-probe-64-e4" --language en
```

## 生成と検証

Windows と .NET 10 SDK が必要です。`6000 × 6000` の 4 階調グレースケール PNG を用意してください。ツールは左上座標 `(2880, 1920)`、大きさ `640 × 640` の固定領域を読みます。Gray8 変換後の値は `0 / 85 / 170 / 255` だけである必要があり、寸法や階調が違う場合は生成を拒否します。入力の拡大縮小や再ディザリングは行いません。サンプル元画像はリポジトリに含まれません。

リポジトリのルートで実行し、`four-level-6000.png` を自分の入力パスに置き換えてください。`prepare` の出力ディレクトリは空である必要があります。

```powershell
dotnet run --project tools/DvdGrayProbe --configuration Release -- prepare --source "four-level-6000.png" --output-dir "artifacts/dvd-gray-probe-64-e4"

dotnet run --project tools/DvdGrayProbe --configuration Release -- generate --prepared "artifacts/dvd-gray-probe-64-e4" --output "artifacts/dvd-gray-probe-64-e4/burn.iso" --parallelism 8

dotnet run --project tools/DvdGrayProbe --configuration Release -- verify --prepared "artifacts/dvd-gray-probe-64-e4" --iso "artifacts/dvd-gray-probe-64-e4/burn.iso"
```

出力ファイル：

| ファイル | 用途 |
|---|---|
| `burn.iso` | 実際に書き込む全ディスクイメージ。2048 バイトのセクター 2,297,888 個、合計 4,706,074,624 バイト |
| `burn.iso.json` | イメージ生成記録と検証情報 |
| `probe.json` | 配置、元画像、パラメーターの記録 |
| `atlas.q8` | Q を直接指定する 6000 × 6000 の目標アトラス |
| `code-map.png` | Q バイトを色で区別する配置ガイド。色は実ディスクの色や明るさを表さない |
| `nominal-preview.png` | 内容を識別するための公称グレー値によるプレビュー。書き込み後の明暗は予測できない |

`burn.iso` は意図的にファイルシステムを含まないセクターイメージであり、正常にマウントできないのは想定どおりです。書き込みソフトの **「イメージをディスクに書き込む / Write image file to disc」** 機能で選択し、通常のファイルとしてデータディスクに追加しないでください。比較のため、43533 ディスクと、前回試験時と同じドライブと速度を使ってください。

**2 枚のガイド PNG を以前のグレースケール画像生成フローに入力しないでください。** 再量子化され、この試験ディスクの `64`、`E4` と混合比を保持できなくなります。

## 試験ディスクの見方

12 時方向から時計回りに 30° のパネルが 12 個あります。ラベル後半は、そのパネルの暗いグレーの候補です。

```text
1-66  2-64  3-E4  |  4-64  5-E4  6-66  |  7-E4  8-66  9-64  |  10-66  11-E4  12-64
```

3 個のパネルごとに同じ入力を使い、パレットは `A5 / candidate / B9 / 92` です。位置による影響を減らすため、候補は別の角度にも反復し、順序を入れ替えています。次の半径はすべてディスク中心から測ります。

| 半径 | 試験内容 |
|---|---|
| 24.5–25.6 mm | 内周の単色。15° ごとに 1 パッチ、`A5、66、64、E4、B9、92` を 4 回反復 |
| 26.0–28.1 mm | 4 階調の蛇行 Floyd–Steinberg グラデーション。全パネルで同じ階調マップを共有し、暗いグレーの byte だけを交換 |
| 28.5–30.5 mm | `64 / E4` の直接混合。各パネルの時計回りの 3 列は `64` が 25%、50%、75% で、残りは `E4` |
| 中心半径 37.5 mm | 同一の 12.8 mm 正方形画像切り抜き |
| 45.8–47.5 mm | 候補と `A5` の混合 |
| 47.8–49.5 mm | 候補と `B9` の混合 |
| 49.8–51.5 mm | 候補と `92` の混合 |
| 52.2–57.3 mm | 内周と同順序の外周単色。byte ラベル付き |

最後の混合 3 行も、各パネルを時計回りに 3 列に分けます。**候補が 25%、50%、75%** で、残りは各行に指定した別の byte です。各候補には同じ 2 値 FS マスクを使います。

百分率は目標ピクセル比率、`0 / 85 / 170 / 255` は公称グレー値です。どちらも実ディスク上の等間隔の明るさを表すものではありません。画像グリッドは **20 µm** で、個々の Q バイトを交互にするのではなく、画像ディザリング後の混合スケールを試験します。

入力は既に 4 階調ディザリング済み PNG です。左上座標 `(2880, 1920)`、大きさ `640 × 640` の領域を、拡大縮小も再ディザリングもせずに切り抜きます。元の実験入力では、この切り抜き内の 4 階調の比率は約 `24.13% / 23.90% / 22.74% / 29.24%` でした。入力を変えると比率は画像に応じて変わります。すべての画像パネルで異なるのは、元の `85` 階調に対応する byte だけです。

このアトラスは混合セル 144 個、有効ピクセル 4,216,432 個について独立検証済みです。空白を除く実際の比率と目標との最大偏差は **0.501 パーセントポイント**、`64/E4` 直接混合行の最大偏差は **0.197 パーセントポイント** で、別の Q バイトの混入はありません。完全な記録は出力ディレクトリの `mixture-measurements.csv` と `mixture-measurements.json` にあります。ISO は長さも確認し、9 個の半径位置で合計 2,359,296 個の payload の目標 Q をバイト単位で照合しました。これらはディジタル出力の検証であり、実ディスクの見え方は書き込み後の観察が必要です。

## 結果の記録

まず同じ光源と通常の観察位置を保ち、隣接する 3 パネルの組を比較します。次にディスクを回し、別の位置にある同じ候補の反復パネルを観察します。最後に視線角度を少し変えて、「通常角度で安定して見える」と「特定角度だけで見える」を区別します。

候補を `A5` と `B9` の両方から区別できるか、混合比を増やすと順序どおりに変わるか、画像の暗部の細部が復元されるか、`64 / E4` 混合が両単色より有用で角度に安定した階調を生むかを確認してください。対照の `B9` は引き続き `A5`、`92` と明瞭に区別できる必要があります。

0 = 区別しにくい、1 = 特定角度で区別できる、2 = 通常角度で安定して区別できる、と簡単に記録できます。

| 候補 | A5 と区別 | B9 と区別 | 混合 3 階調が順序どおりで識別可能 | 画像暗部の細部 | 備考 |
|---|---|---|---|---|---|
| 66 | | | | | |
| 64 | | | | | |
| E4 | | | | | |

`64 / E4` の 25%、50%、75% の 3 階調を相互に区別できるか、特定角度でしか有効でないかも記録します。4 番目の階調を採用するかは、この実ディスクの結果に基づいて判断します。

## 固定キャリブレーションパラメーター

今回は確認済みの 43533 キャリブレーションパラメーターを使用します。

- 開始半径：`23.991460627731737 mm`
- 終了半径：`57.964893657925366 mm`
- セクター数：`2297888`
- チャネルビット長：`133.3 nm`
- トラックピッチ多項式の係数：`[-3.9256854319227684E-05, 6.964795915429256E-05, -4.670918950137523E-05]`
- アトラス：`6000 × 6000`、範囲 `120 × 120 mm`

これらのパラメーターは、このディスクの空間マッピングに使用します。ガイド画像は物理的な明るさのモデルではありません。
