# 獨立 17PP 參考實作

[简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [English](README.md) | [日本語](README.ja.md) | [Türkçe](README.tr.md)

這些使用 Python 標準函式庫的工具，依使用者提供的 ISO/IEC 30190:2021 第 13.17 節與圖 41 轉錄而成。本實作不匯入正式使用的 C# 編碼器。有限長度參考實作已與 C# 對照檢查全部 256 種四位元組重複輸入及 298 個有限位元模式向量，結果全部一致。輸出產物包含預期向量。

在儲存庫根目錄執行：

```powershell
python tools/BluRayByteProbe/reference/analyze.py --output-dir artifacts/bluray-byte-density/reference
python tools/BluRayByteProbe/reference/pattern_search.py --output-dir artifacts/bluray-byte-density/reference
python tools/BluRayByteProbe/reference/robust_pattern_search.py --output-dir artifacts/bluray-byte-density/reference
```

`--output-dir` 預設為目前目錄。兩種模式搜尋都接受 `--max-period`（預設 16）。不需要外部 Python 套件。

三個 Python 工具的說明、進度、錯誤及說明性 JSON 文案皆支援五種語言，共用 `--language zh-CN|zh-TW|en|ja|tr|system` 與 `DISC_IMAGE_STUDIO_LANGUAGE`；明確選項優先，否則跟隨系統介面語言。語言選擇不改變欄位名稱、CSV 欄、精確比率、位元序列或數值剖析，參考演算法仍獨立於 C# 編碼器。

```powershell
python tools/BluRayByteProbe/reference/analyze.py --language ja --help
```

## 測量域

此處使用的是 **17PP 輸入端經過擾碼後的輸入**，位於任何明確建模的 DC 插入之前，而不是原始 host payload 模式。密度等於調變位元 1 的數量除以通道位元數量：一個調變位元 1 會翻轉 NRZI 記錄電平。統計*調變位元之間*的變化，測量的是另一種量。

`analyze.py` 從兩種可能的前一調變位元分別開始，為每種重複位元組及全部八種輸入位元相位計算精確循環。它將位元組結果儲存為 JSON/CSV，並儲存四位元組有限向量。基準不包含 EDC、RS 同位檢查、LDC 交錯、BIS、同步與 DC 位元。固定 DC 結果在每 45 個來源位元後無限重複插入一個控制位元；它們是敏感度診斷，不是合法的完整記錄框架或 DC 平衡輸出。

`pattern_search.py` 使用兩種可能的前一調變位元，明確評估長度 2 至 16 的全部 131,068 個二進位字串（262,136 次精確循環評估）。它驗證密度在每次旋轉兩個輸入位元及改變前一位元時不變，再歸併為 14,694 個對應旋轉類別。奇數週期只有一個旋轉軌道；偶數週期保留獨立的奇／偶對齊類別。報告每個長度的極值時，仍保留等價模式與較短模式的重複，因此這些是週期長度，不一定是最小週期。

`robust_pattern_search.py` 依完整位元旋轉分類，並比較兩種位元對相位。**在搜尋的週期長度範圍內**，它找到的相位穩健最小值為 1/6，最大值為 4/9。不宣稱這兩個穩健結果是更長週期的全域界限。

NRZI 電平 1 佔比採用初始電平零；反轉初始電平會使佔比互補。50% 的工作週期不能預測光學結果是黑或白。

## 可達通道密度界限

對任意長的 17PP 調變資料段，每個游程最多為 8T，因此跳變密度至少為 1/8。16 位元輸入循環 `0000101101110010`（重複 `0B 72`）透過輸出循環 `000100000001000000010000` 達到此界限，即三個 8T 游程。

另一個極端是連續 2T 游程最多為六個。將每段至多六個 2T 游程與其後至少 3T 的游程歸為一組，可得密度最多為 7/15。10 位元輸入循環 `0111011110`（封裝為重複的 `77 9D E7 79 DE`）達到此值：輸出循環 `101010101001010`，即六個 2T 游程與一個 3T 游程。這些是實際查表產生的循環，不只是 RLL 理論界限。兩個極值在完整電平循環中均有 50% 的 NRZI 佔比。

這些界限適用於長資料段。框架同步具有特殊的 9T 游程，不屬於一般 17PP 規則；有限長度終止與其他實體框架開銷必須另行計入。

| 輸入模式 | 此相位下的封裝方式 | 密度 | 輸出循環中的游程 | 奇數輸入位元相位 |
|---|---|---:|---|---:|
| `0001` | 重複 `11` | 1/6 = 16.6667% | 6T | 1/6 |
| `00111101` | 重複 `3D` | 5/12 = 41.6667% | 三個 2T + 兩個 3T | 5/12 |
| `001111` | 重複 `3C F3 CF` | 4/9 = 44.4444% | 三個 2T + 一個 3T | 4/9 |
| `0000101101110010` | 重複 `0B 72` | 1/8 = 12.5% | 三個 8T | 7/24 |
| `0111011110` | 重複 `77 9D E7 79 DE` | 7/15 = 46.6667% | 六個 2T + 一個 3T | 1/3 |

六位元高密度候選在未進行 DC 平衡時的 NRZI 工作週期為 4/9 或 5/9，視極性而定；DC 平衡會改變該值。它對位元對相位的穩健性，使它成為重複位元組之外值得繼續測試的候選。盲目向兩個極端模式插入 DC 位元，會破壞其有利對齊。

## 在實體配置中保持模式

一種有用的細粒度映射，是依最終實體位置選擇每個可控使用者位元。對插入 DC 前的框架位元索引 `j`，其前方的 DC 插入位置數在 `j < 25` 時為 `0`，否則為 `1 + floor((j - 25) / 45)`。選擇模式位元 `P[(j + dcBefore(j) + phase) mod period]`，預留 DC 位置，而非讓插入操作移走預期模式。實際 DC 值仍由光碟機選擇，且仍會擾動相鄰碼字。在 DC 區塊處重設相位，是另一種值得實驗比較的策略。

先依記錄框架／ECC 位元組順序構造此序列，再使用現有 LDC 排列的逆映射，將可控使用者位元組放入擾碼後的 payload。套用對應的擾碼遮罩可還原 host 位元組。在 host 或來源磁區順序中重複的位元組模式，通常不會在交錯後仍維持週期性。EDC、LDC 同位檢查、BIS、同步與 DC 值並非可獨立設定的 payload 位元；完整管線測量應計入它們，而不是將每個框架位元都視為可控。

密度與 NRZI 工作週期都不決定最終黑白極性。已燒錄色塊的反射率與可見度仍須實測。
