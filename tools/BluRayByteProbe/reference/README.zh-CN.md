# 独立 17PP 参考实现

[简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [English](README.md) | [日本語](README.ja.md) | [Türkçe](README.tr.md)

这些使用 Python 标准库的工具根据用户提供的 ISO/IEC 30190:2021 第 13.17 节与图 41 转录而成。本实现不导入生产用 C# 编码器。有限长度参考实现已与 C# 对照检查全部 256 种四字节重复输入和 298 个有限位模式向量，结果全部一致。输出产物中包含预期向量。

在仓库根目录运行：

```powershell
python tools/BluRayByteProbe/reference/analyze.py --output-dir artifacts/bluray-byte-density/reference
python tools/BluRayByteProbe/reference/pattern_search.py --output-dir artifacts/bluray-byte-density/reference
python tools/BluRayByteProbe/reference/robust_pattern_search.py --output-dir artifacts/bluray-byte-density/reference
```

`--output-dir` 默认为当前目录。两种模式搜索都接受 `--max-period`（默认 16）。不需要外部 Python 包。

三个 Python 工具的帮助、进度、错误和说明性 JSON 文案均支持五种语言，共用 `--language zh-CN|zh-TW|en|ja|tr|system` 与 `DISC_IMAGE_STUDIO_LANGUAGE`；显式选项优先，否则跟随系统界面语言。语言选择不改变字段名、CSV 列、精确比率、位序列或数值解析，参考算法仍独立于 C# 编码器。

```powershell
python tools/BluRayByteProbe/reference/analyze.py --language ja --help
```

## 测量域

这里使用的是 **17PP 输入端经过扰码后的输入**，位于任何显式建模的 DC 插入之前，而不是原始 host payload 模式。密度等于调制位 1 的数量除以通道位数量：一个调制位 1 会翻转 NRZI 记录电平。统计*调制位之间*的变化测量的是另一种量。

`analyze.py` 从两种可能的前一调制位分别开始，为每种重复字节和全部八种输入位相位计算精确的循环。它将字节结果保存为 JSON/CSV，并保存四字节有限向量。基线不含 EDC、RS 校验、LDC 交织、BIS、同步和 DC 位。固定 DC 结果在每 45 个源位后无限重复插入一个控制位；它们用于敏感性诊断，不是合法的完整记录帧或 DC 平衡输出。

`pattern_search.py` 使用两种可能的前一调制位，显式评估长度 2 至 16 的全部 131,068 个二进制串（262,136 次精确循环评估）。它验证密度在每次旋转两个输入位及改变前一位时不变，然后归并为 14,694 个对应旋转类。奇数周期只有一个旋转轨道；偶数周期保留独立的奇／偶对齐类。报告每个长度的极值时仍保留等价模式及更短模式的重复，因此这些是周期长度，不一定是最小周期。

`robust_pattern_search.py` 按完整的位旋转归类，并比较两种位对相位。**在搜索的周期长度范围内**，它找到的相位稳健最小值为 1/6，最大值为 4/9。不声称这两个稳健结果是更长周期的全局界限。

NRZI 电平 1 占比采用初始电平零；反转初始电平会使占比互补。50% 的占空比不能预测光学结果是黑还是白。

## 可达通道密度界限

对于任意长的 17PP 调制数据段，每个游程最多为 8T，因此跳变密度至少为 1/8。16 位输入循环 `0000101101110010`（重复 `0B 72`）通过输出循环 `000100000001000000010000` 达到此界限，即三个 8T 游程。

另一个极端是连续 2T 游程最多为六个。将每段至多六个 2T 游程与其后至少 3T 的游程归为一组，可得密度最多为 7/15。10 位输入循环 `0111011110`（打包为重复的 `77 9D E7 79 DE`）达到此值：输出循环 `101010101001010`，即六个 2T 游程和一个 3T 游程。这些是实际查表生成的循环，不仅是 RLL 理论界限。两个极值在完整的电平循环中均有 50% 的 NRZI 占比。

这些界限适用于长数据段。帧同步具有特殊的 9T 游程，不属于普通 17PP 规则；有限长度终止和其他物理成帧开销必须另行计入。

| 输入模式 | 此相位下的打包方式 | 密度 | 输出循环中的游程 | 奇数输入位相位 |
|---|---|---:|---|---:|
| `0001` | 重复 `11` | 1/6 = 16.6667% | 6T | 1/6 |
| `00111101` | 重复 `3D` | 5/12 = 41.6667% | 三个 2T + 两个 3T | 5/12 |
| `001111` | 重复 `3C F3 CF` | 4/9 = 44.4444% | 三个 2T + 一个 3T | 4/9 |
| `0000101101110010` | 重复 `0B 72` | 1/8 = 12.5% | 三个 8T | 7/24 |
| `0111011110` | 重复 `77 9D E7 79 DE` | 7/15 = 46.6667% | 六个 2T + 一个 3T | 1/3 |

六位高密度候选在未进行 DC 平衡时的 NRZI 占空比为 4/9 或 5/9，具体取决于极性；DC 平衡会改变这个值。它对位对相位的稳健性，使它成为重复字节之外值得继续测试的候选。盲目向两个极端模式插入 DC 位会破坏其有利对齐。

## 在物理布局中保持模式

一种有用的细粒度映射是按最终物理位置选择每个可控用户位。对于插入 DC 前的帧位索引 `j`，其前面的 DC 插入位置数在 `j < 25` 时为 `0`，否则为 `1 + floor((j - 25) / 45)`。选择模式位 `P[(j + dcBefore(j) + phase) mod period]`，预留 DC 位置，而不是让插入操作移走预期模式。实际 DC 值仍由光驱选择，且仍会扰动相邻码字。在 DC 块处重置相位是另一种值得实验比较的策略。

先按记录帧／ECC 字节顺序构造这一序列，再使用现有 LDC 排列的逆映射，将可控用户字节放入扰码后的 payload。应用相应的扰码掩码可恢复 host 字节。在 host 或源扇区顺序中重复的字节模式，通常不会在交织后仍保持周期性。EDC、LDC 校验、BIS、同步与 DC 值并非可独立设置的 payload 位；完整管线测量应计入它们，而不是把每个帧位都视为可控。

密度与 NRZI 占空比都不决定最终黑白极性。已刻录色块的反射率与可见度仍须实测。
