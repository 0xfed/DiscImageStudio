# 固定キャリブレーション参照画像

[简体中文](README.md) | [繁體中文](README.zh-TW.md) | [English](README.en.md) | [日本語](README.ja.md) | [Türkçe](README.tr.md)

`target_slim.png` は、ユーザーが指定した画像を変更せずに複製した 2400×2400 RGB 画像です。ファイルの SHA-256：

```text
c98ffe87db7cf9c3f132352814e1ce611c44f704de5b7212da4083188257c829
```

元画像の 3 つの色チャンネルは、ピクセルごとに同じ値です。`target_slim.gray.gz` は、二値化していない 8 ビットのグレースケールピクセルを行順に格納し、GZip で圧縮しています。展開後は 5,760,000 バイトで、SHA-256 は次のとおりです。

```text
3d351bdfb817b943c1d1b4aedc97fc4f0a111e7e1537748f70cb5b180ba96852
```

画像は生成時の外半径に合わせて拡大縮小され、通常の画像エンコーダーと同じピクセル座標規約を使用します。DVD のピクセル中心基準は `1199.5`、CD は `1200` です。ディスク中心を原点とする座標は
`((x-centre)*outerRadius/centre, (y-centre)*outerRadius/centre)` mm で、Y 軸は下向きです。9 個の円の元画像上の参照半径は
490、570、650、730、810、890、970、1050、1130 ピクセルです。線幅は約 10 ピクセルで、実際のミリメートル寸法は生成時の外半径に比例して変わります。

符号化、プレビュー、PNG エクスポートはこの画像を共有し、まず外半径に合わせて拡大縮小してから、内外半径の間の描画領域に切り取ります。プレビューの 120 mm ディスク背景は、画像の符号化スケールを決定しません。画像を解析して描き直してはいません。`CalibrationEncoderTests` は、元の PNG ハッシュ、すべてのグレースケールピクセル、ネイティブのプレビューとエクスポート、および CD/DVD のファイルとストリームの一致を検証します。
