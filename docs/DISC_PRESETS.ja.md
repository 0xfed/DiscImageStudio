# 編集可能なディスクプリセット

[简体中文](DISC_PRESETS.md) | [繁體中文](DISC_PRESETS.zh-TW.md) | [English](DISC_PRESETS.en.md) | [日本語](DISC_PRESETS.ja.md) | [Türkçe](DISC_PRESETS.tr.md)

## 使用可能容量と保存済みプリセットの適用

形状の総セクター数が完全な螺旋を決定し、省略可能な `usableSectors` が出力長、ファイルシステム容量、使用可能領域の外半径を制限します。明示値から予約領域を再び差し引きません。古いプリセットやプロジェクトで省略された場合、CD は総数から 2 を引き、DVD は 608 を引いて 16 単位で切り下げ、BD は 32 単位で切り下げます。内蔵プリセットは明示値を持ちます。DVD の形状総数は整列不要ですが、出力は整列が必要です。

既存プロジェクトでプリセットを保存すると直ちに適用して選択し、プレビューの実測半径とピッチも同期します。その後ダイアログをキャンセルしても保存した値は保持し、以後の未確定編集は破棄します。名前だけの変更は手動測定値を保持します。新規プロジェクトからの保存は現在のプロジェクトを変えず、同名プリセットも別 ID を持ちます。

ディスクプリセットは 2 つの層に分かれます。

- 組み込み層はアプリケーションとともに配布・更新され、公式プリセットを保持します。
- ユーザー層は次のファイルに保存され、ユーザーによる追加、上書き、無効化設定のみを保持します。

```text
%LOCALAPPDATA%\DiscImageStudio\disc-presets.json
```

初回起動時、アプリケーションはユーザー層に「カスタム CD パラメーター」「カスタム DVD パラメーター」「カスタム Blu-ray パラメーター」という 3 つの編集可能なプリセットを作成します。組み込みプリセットはユーザーファイルにコピーされないため、アプリケーション更新時のパラメーター修正やプリセット追加が自動的に反映されます。

ユーザープリセットはプロジェクト設定ダイアログから追加します。「このパラメーターをプリセットとして保存」で別ウィンドウに名前の確認を表示し、現在のパラメーターをユーザー層に追加します。新規プロジェクトのテンプレート一覧には、カタログ内の手動以外のすべてのプリセットが「最近」「CD」「DVD」「Blu-ray」に分類されて表示されます。

プロジェクト設定ダイアログにも現在のディスク種類のプリセットが表示されます。別のプリセットを選択するとダイアログの幾何パラメーターを上書きするため、切り替え前に確認を表示します。キャンセルすると元のパラメーターと選択項目を維持します。新規プロジェクトとプロジェクト設定の「カスタム」プリセットは右クリックメニューから削除できます。削除は直ちにユーザー層に書き戻され、一覧が更新されます。JSON を直接編集して追加、改名、無効化した場合は、引き続き再起動が必要です。

## マージ規則

- ユーザープリセットが新しい `id` を使用する場合、組み込みプリセットの後に追加されます。
- ユーザープリセットが組み込みプリセットと同じ `id` を使用する場合、その組み込みプリセット全体を上書きします。
- `disabledCdPresetIds`、`disabledDvdPresetIds`、`disabledBluRayPresetIds` で不要な組み込みまたはユーザープリセットを非表示にできます。
- 組み込みプリセットの更新時、同じ ID のユーザー項目で上書きされていないパラメーターは自動更新されます。

## DVD プリセットの追加

`dvdPresets` 配列内の初期化済みユーザーオブジェクトをコピーし、`id`、名前、パラメーターを変更します。例：

```json
{
  "id": "verbatim-dvd-r-azo-43533",
  "displayName": "Verbatim DVD-R AZO (43533)（実測）",
  "description": "Verbatim DVD-R AZO 43533 の検証済み校正パラメーター：23.9914606277–57.9648936579 mm、2,297,888 セクター。3 次トラックピッチ分布を使用。",
  "totalSectors": 2297888,
  "innerRadiusMm": 23.991460627731737,
  "outerRadiusMm": 57.964893657925366,
  "channelBitLengthNm": 133.3,
  "pitchLinear": -3.9256854319227684E-05,
  "pitchQuadratic": 6.964795915429256E-05,
  "pitchCubic": -4.670918950137523E-05
}
```

DVD の `totalSectors` は、ECC Block とストリーミング書き込みの配置要件を満たすため、0 より大きい 16 の倍数である必要があります。`channelBitLengthNm` は予約フィールドです。後の節を参照してください。

この Verbatim DVD プリセットは、ユーザーが検証済みと確認した `calibration-f2f851f7.calibration.json` に由来し、記録中のパラメーターの完全な精度を維持しています。

任意の `contributor` フィールドは、この実測パラメーターを提供した貢献者を記録します。指定するとプリセットカードの左上に苗のアイコンが表示され、マウスを重ねると直ちに「貢献者：…」が表示されます。フィールドを省略または空にするとアイコンは表示されません。空白のみの値は検証で拒否されます。組み込みの `philips-dvd-plus-r` の例：

```json
{
  "id": "philips-dvd-plus-r",
  "displayName": "PHILIPS DVD+R（実測）",
  "description": "PHILIPS DVD+R の実測校正パラメーター：24.157724–57.881039 mm、2,295,104 セクター。3 次トラックピッチ分布を使用。",
  "totalSectors": 2295104,
  "innerRadiusMm": 24.157723798864616,
  "outerRadiusMm": 57.881039159257099,
  "channelBitLengthNm": 133.3,
  "pitchLinear": -0.00015487792452410765,
  "pitchQuadratic": 0.0001962455822194293,
  "pitchCubic": -8.6683602888291885E-05,
  "contributor": "DBPolp"
}
```

`pitchLinear`、`pitchQuadratic`、`pitchCubic` は、3 次トラックピッチの 3 つの相対形状係数です。既定は 0 で、旧プリセットと互換です。モデルは `p(x)=p0*(1+pitchLinear*x+pitchQuadratic*x²+pitchCubic*x³)`、`x=(r-innerRadiusMm)/(outerRadiusMm-innerRadiusMm)` です。完全な多項式は 4 項で、`p0` は総トラック長から自動計算し、画面には全 4 項の実際の μm 値を表示します。`0≤x≤1` の全区間でピッチは厳密に正である必要があり、内外の境界だけのチェックでは不十分です。いずれかの係数を変更すると未保存のカスタム状態になり、組み込みの等ピッチプリセットを再選択すると係数は 0 に戻ります。

組み込みの実測 DVD プリセットには `verbatim-dvd-plus-r-azo-43498`（Verbatim DVD+R AZO (43498)、貢献者 `Disappear9`）、`ritek-dvd-plus-r-e-series`（Ritek DVD+R E シリーズ、貢献者 `EternalEve`）、`ritek-dvd-r-e-series`（Ritek DVD-R E シリーズ、貢献者 `bczhc`）もあります。

`verbatim-dvd-plus-r-azo-43498` のパラメーターは、内半径 `23.954070288547207` mm、外半径 `57.981456053451275` mm、`2,295,104` セクター、3 次ピッチの形状係数 `-1.1055153059816393E-05`、`-1.7233535436312236E-06`、`5.55123860136712E-06` です。`ritek-dvd-r-e-series` のパラメーターは、内半径 `24.063109184084034` mm、外半径 `58.23373375457525` mm、`2,298,496` セクター、3 次ピッチの形状係数 `-3.2229430281730407E-06`、`1.0507210681810583E-05`、`-8.562064227346657E-06` です。いずれも元の値の完全な精度を維持しています。

## CD プリセットの追加

`cdPresets` 配列内の既存オブジェクトをコピーし、`id`、名前、セクター数、内外半径を変更します。例：

```json
{
  "id": "cd-74",
  "displayName": "標準 74min CD",
  "description": "ECMA-130／ISO/IEC 10149 の標準速度 1200 mm/s。120 mm ディスク、約 74 分、333,000 セクター（24.5–56.8 mm）。",
  "sectors": 333000,
  "innerRadiusMm": 24.5,
  "outerRadiusMm": 56.8,
  "linearVelocityMmPerSecond": 1200
}
```

## Blu-ray プリセットの追加

`bluRayPresets` 配列内の既存オブジェクトをコピーし、`id`、名前、パラメーターを変更します。例：

```json
{
  "id": "bd-r-ritek-10x",
  "displayName": "Ritek BD-R 10x（実測）",
  "description": "実測パラメーター：内半径 23.988221 mm、外半径 58.023235 mm、12,219,392 セクター。",
  "totalSectors": 12219392,
  "innerRadiusMm": 23.98822105616562,
  "outerRadiusMm": 58.023234731100764,
  "invertMapping": false
}
```

BD の `totalSectors` は 0 より大きく、32 単位に整列し、単層容量 12,219,392 以下である必要があります。外半径は 60 mm 以下です。`invertMapping` はプリセットの 3T/6T 極性で、プロジェクトに適用した後もデザインページのトーンモジュールで変更できます。

組み込みの `bd-r-verbatim-64099`（Verbatim BD-R (64099)）は、ユーザーの `disc-presets.json` に保存済みの「Verbatim 64099」プリセットを使用し、完全な精度を維持しています。内半径 `23.987042157339335` mm、外半径 `57.987960341783236` mm、`12,219,392` セクター、`invertMapping: false` です。GUI とコマンドラインは同じパラメーターを使用します。

組み込みの `bd-r-verbatim-64293`（Verbatim BD-R (64293)）は貢献者 `bczhc` の提供で、64099 と同じパラメーターを使用し、同じ精度を維持しています。

組み込みの `bd-r-ritek-12x`（Ritek BD-R 12x）は貢献者 `DeepAQ` の提供です。内半径 `23.98795` mm、外半径 `58.02236` mm、`12,219,392` セクター、`invertMapping: false` です。GUI とコマンドラインは同じパラメーターを使用します。

## 固定パラメーターと予約フィールド

走査速度、開始角、画像の外半径、DVD チャネルビット長は、この方式では固定の物理量です。画面に対応する入力欄はなく、生成時は常に 1200 mm/s（ECMA-130）、0°、57.5 mm、133.3 nm を使用します。

旧バージョンの設定ファイルではこれらのパラメーターが必要だったため、旧バージョンで書き出したユーザーファイルをそのまま使用できるよう、JSON には引き続きフィールドを残しています。これらの予約値は生成計算には使用しません。

## i18n 互換フィールド

デスクトップアプリケーションは登録済みの `displayNameResourceKey` と `descriptionResourceKey` を優先して解決し、キーが存在しなければ既存テキストにフォールバックします。変更されていない組み込みの名前と説明も翻訳し、ユーザーが入力した名前と説明は原文を維持します。アプリケーションが保存する幾何の説明には `DiscPreset.UserDescription` 書式キーを使用し、プリセットの半径とセクター数から表示時に翻訳します。旧プリセット内の説明も、自動生成の書式と完全に一致する場合は認識されます。説明を手動で変更すると、書式キーが残っていても原文を維持します。ユーザープリセットにリソースキーを指定する必要はありません。`fallbackLanguage` は引き続き任意の元言語メタデータであり、UI 言語の選択は変更しません。 初期ユーザープリセットも、メディア種類と ID が一致し、テキストが未編集の場合は、表示時に既定の文言を翻訳します。

## 編集規則

- 現在の最上位は `"schemaVersion": 4` で、`cdPresets`、`dvdPresets`、`bluRayPresets`、3 つの無効化リスト、任意の `fallbackLanguage` を含みます。`"schemaVersion": 2` と `3` も受け付けます。BD カタログがない場合は組み込み BD テンプレートで補完し、保存時に 4 に更新します。
- 各プリセットグループ内の `id` は一意である必要があります。`__manual__` は画面の「未保存のカスタムパラメーター」状態用の予約 ID で、JSON に書き込めません。
- テンプレートに記載された生成パラメーターのみ指定できます。画像配置や校正パラメーターがディスクプリセットに混入しないよう、その他のフィールドは拒否します。
- 半径、`linearVelocityMmPerSecond`、`channelBitLengthNm` は 0 より大きい有限値で、生成外半径は生成内半径より大きい必要があります。
- ファイルでは `//` または `/* ... */` のコメントと配列末尾のカンマを使用できます。
- 形式やパラメーターが無効な場合、アプリケーションは問題を示して最後に正常に読み込めたプリセットを維持し、ユーザーファイルを自動上書きしません。
