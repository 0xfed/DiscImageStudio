# Disc Image Studio Privacy Policy

[简体中文](PRIVACY.md) | [繁體中文](PRIVACY.zh-TW.md) | [English](PRIVACY.en.md) | [日本語](PRIVACY.ja.md) | [Türkçe](PRIVACY.tr.md)

Effective date: August 21, 2026

Disc Image Studio (光盘绘图工坊) is a disc image generation tool that runs entirely locally on a Windows device.

## Data processing

- The application reads only images, folders, ISO files, or raw audio track files that the user explicitly selects.
- The application generates ISO, RAW, PNG, BIN, and JSON files only at locations specified by the user.
- The application has no network communication features. It does not upload user files or collect telemetry, advertising identifiers, location, contacts, account information, or other personal information.
- The application does not use third-party analytics, advertising, or cloud storage services.

Users can delete files generated by the application at any time through Windows File Explorer. Uninstalling the application does not automatically delete output files that users explicitly saved to the Documents folder or other locations.

If a future version adds networking, accounts, telemetry, or other data processing features, this policy will be updated before that version is released, and user consent will be obtained where applicable.
